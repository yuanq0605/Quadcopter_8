### 2.2 P1 封装的排针列距 = 6.00mm，2×19 排母应为 2.54mm

> 补充：设计者计划用**两个 2×19 贴片排母**与 Nucleo 的 2×19 双排针配合。
> 无论排母是贴片还是插件、是排针还是排母，2.54mm 针距的双排件其**双排列距恒为 2.54mm**，
> 因此本条不受贴片方案影响，仍然成立。

- 当前 DRC 记录：`P1-1 (3.934, 51.41)`、`P1-2 (9.934, 51.41)` → 两列相距 **6.000mm**
- Gerber 实测：4 列 × 19 个焊盘，列坐标 20.568 / 26.568 / 79.368 / 85.368，
  每列 19 个、间距 2.54mm、同侧两列相距 **6.000mm**
- 结构正确（奇数脚一列、偶数脚一列，38 脚 = 2×19），但**列距是 6.00mm**

Nucleo-64 的 CN7/CN10 是标准 2×19、2.54mm 排针，双排列距 = 针距 = 2.54mm。
按 Nucleo 实物图测量，CN7 两列间距与针距基本相同（≈2.54mm）。

若确实如此，则每个排针有一整列 19 个焊盘偏移 **3.46mm**，开发板插不进去。

> 复核方法：在 AD 中打开 `AD.PcbLib` 的 NUCLEO-F103RB，量 CN7 两列焊盘中心距；
> 对照 UM1724 的机械图。若为 6.00mm，改为 2.54mm 后重新布线。

### 2.3 76 个 Nucleo 焊盘是"贴片型 + 带钻孔"（贴片排母方案 → 应取消钻孔）

DRC：`WARNING: Drilled SMT Pads found`，共 **76 个**（P1-1…38、P1-73…110）。
Gerber 佐证：这 76 个焊盘只有单面铜箔，另一面完全无铜；同时钻孔文件里有 0.9mm 镀通孔。

采用**贴片排母**后，这条问题依然存在，但修法要改：

- 贴片排母贴装在同一面，引脚**不穿过板子**，所以焊盘应当是**纯贴片（无钻孔）**。
- 现在每个贴片焊盘中心被打了一个 0.9mm 镀通孔，会产生三个副作用：
  1. 焊接时焊锡顺着镀通孔流到无铜的另一面，形成锡珠/连锡；
  2. 焊盘有效面积被挖掉，贴片排母的焊接强度下降；
  3. DRC 的 Drilled SMT Pads 警告永远消不掉。
- 正确做法：把 P1-1…38、P1-73…110 的 **Hole Size 改为 0**，层保持单面贴片，
  焊盘尺寸按所选贴片排母的规格书 land pattern 做（2.54 针距常见 1.0×2.0 / 1.5×2.0mm）。
- 若所选贴片排母带**塑料定位柱**，应另加 2 个 NPTH 孔作为定位孔（目前全板没有任何 NPTH 孔）。
- 机械强度提醒：整块 Nucleo 的重量和反复插拔的力全部由 76 个贴片焊点承担，
  没有通孔做机械锚定。优先选带定位柱的贴片排母；若插拔频繁，建议改回通孔排母
  （此时焊盘才应改为 Multi-Layer，孔径 1.0mm、环径 1.6–1.8mm）。

另外 P1 的 39–72 号焊盘在 Gerber 中既无铜也无孔，属残留空焊盘，建议在封装里清掉。

### 2.4 供电走的是 E5V，必须改 Nucleo 的 JP5

`+5` 接的是 CN7-6 = **E5V**（外部 5V 输入），不是 CN7-18 的 +5V。
NUCLEO-64 的 JP5 默认在 **U5V**（USB 供电）位置，此时 E5V 与板内 5V 轨断开
→ 板子完全不供电，+3V3 也为 0，OLED / HM-10 全不亮。

**上电前把 JP5 跳到 E5V 位置。**
（不建议改接 CN7-18 的 +5V：会经 JP5 反灌 ST-LINK/U5V。）

### 2.5 Nucleo 只用 1 个 GND 引脚

整个 GND 网络只通过 **CN7-19 一个 2.54 排针**回到 Nucleo。
而 CN7-8/20/22、CN10-9/20/32 全都是 GND，一个没用。

这条单点回流要同时承受：电池回路、GY-86、HM-10、OLED、SBUS 模块、
以及 4 路电调的 PWM 地参考。电流不大（<300mA），但地弹和 PWM 抖动风险实打实。

建议至少并联 3 个 GND 脚。可用的 GND 焊盘（P1 编号 → 排针脚位）：

| 侧 | P1 焊盘 | 对应 | 现状 |
|---|---|---|---|
| CN7 侧 | P1-8 | CN7-8 GND | 未接 |
| CN7 侧 | **P1-19** | CN7-19 GND | 已接（唯一） |
| CN7 侧 | P1-20 | CN7-20 GND | 未接 |
| CN7 侧 | P1-22 | CN7-22 GND | 未接 |
| CN10 侧 | P1-81 | CN10-9 GND | 未接 |
| CN10 侧 | P1-92 | CN10-20 GND | 未接 |
| CN10 侧 | P1-104 | CN10-32 AGND | 未接 |

**特别要点：CN10 一侧当前一个地都没有。** 而 PA6/PA7/PB1/PB3/PB6/PB9/PA9/PA10/PA11/PA12
这些信号几乎全在 CN10 侧，等于所有高速与 PWM 信号都跨板取地。
建议至少补 P1-81 和 P1-92（CN10 侧），CN7 侧再补 P1-8 或 P1-20，合计 3–5 个接地点。

另外 GND 走线宽度设的是 0.4mm，比 +5/+3V3 的 1.0mm 还窄，建议加宽到 ≥1mm 或依赖铺铜。

## 4. 建议改进（不阻塞投板）

1. **全板没有一颗电容**。不会致命，但会牺牲噪声裕量。风险集中在三处：
   (a) MPU6050 对电源纹波敏感，纹波会表现为陀螺零偏漂移；
   (b) OLED 模块自带电荷泵，其开关噪声会经 +3V3 串到 HM-10；
   (c) I2C 上拉在模块端（离 MCU 远），无本地去耦时边沿易振铃。
   建议加（成本几毛钱）：XT-30 入口 100µF 电解 + 100nF；
   开关后 +5 轨 10µF + 100nF；GY-86 座旁 100nF + 1µF；OLED 与 HM-10 座旁各 100nF。
   +3V3 由 Nucleo 板载 LDO 输出、板上已有电容，风险小于 +5/电池侧。
2. **没有 I2C 上拉**。目前依赖 GY-86（板载 4.7k）和 OLED 模块（一般 10k）。
   若换成无上拉的 OLED，I2C2 会死。建议板上各留 4.7k 位置（可不焊）。
3. **P3/P4 的 VCC 脚是悬空的**。10/15 的 ECO 把 +5 从 P3-3 删掉了，P3-4/P4-3/P4-4
   就一直是空脚；但符号里这几脚名字叫 VCC，容易误导。
   建议要么接 +5（注意电调 BEC 反灌），要么在符号里改成 NC 并在丝印标注。
4. **P2 的排针顺序与原装线序不同**。SBUS转TTL 模块原装单片机侧是 **GND / 5V / RX**（3 针），
   而板上 P2 是 1=RX 2=TX 3=5V 4=GND（4 针）。用杜邦线单独接没问题，
   但**丝印必须逐针标清**，否则按原装 3 针线序插会烧模块。
5. **P2 与 Nucleo 自带 USB 抢 PA11/PA12**。USART6 用的是 USB OTG FS 的 D-/D+。
   插着 CN13 的 USB 时，主机 D+/D- 会和 SBUS 模块的 TX/RX 打架。
   使用时不要同时插 USB。
6. **板上没有任何安装孔**。钻孔文件里没有非镀铜孔（只有 0.9/0.9144/1.1/1.8mm 镀通孔）。
   四轴上装不牢，建议加 2–4 个 M3（3.2mm）或 M2.5 定位孔。
7. **没有测试点**。建议给 +5、+3V3、GND、4 路 PWM、两路串口各留一个焊盘 TP。
8. **开关 U1 (SS12D06) 的额定电流**要核对。常见规格 0.3A/50V 或 1A/30V。
   整板负载约 150–250mA，0.3A 的型号余量偏小。
9. **`NetU1_2` 是自动命名**（电池+到开关输入）。功能没问题，
   建议改成 `VBAT` 之类，便于阅读和查 DRC。
10. **+3V3 曾短接到 CN7-18（+5V 脚）**，10/21 加入、11/6 删除。现已修正，
    确认当前 +3V3 只接 CN7-16。这也再次说明 10/16 的旧 Gerber 不能直接用。

## 5. 固件侧两点提醒（不是 PCB 问题，但会影响"能不能跑"）

1. **SBUS 波特率/格式不匹配**。`usart.c` 里 USART6 是 `115200 8N1`，
   而 SBUS 是 `100000 baud / 8 数据位 / 偶校验 / 2 停止位`（电平反相由转换板处理）。
   当前配置收不到 SBUS，需改成 100000 + `UART_PARITY_EVEN` + `UART_STOPBITS_2`。
2. `Picture\引脚配置.png` 是旧版截图（PA2/PA3 = USART2），
   当前 `.ioc` 已改为 PA11/PA12 = USART6，以 `.ioc` 为准。

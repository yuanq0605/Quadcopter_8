# 挑战点三：应用AD设计STM32硬件PCB

## 一、PCB封装的绘制
### （一）、PCB封装元素组成
* **PCB焊盘**：用于焊接元件管脚的载体
* **管脚序号**：用于和元件进行电气连接关系匹配的序号
* **元件丝印**：用于描述元件腔体大小的识别框
* **阻焊**：防止绿油覆盖，可以有效地保护焊盘焊接区域
* **1脚标识 / 极性标识**：用于定位元件方向的标识符号

### （二）、简单PCB封装
>**查看PCB封装的3D模型**：按快捷键ctrl + D，将3D修改为On即可显示3D模型，按住shift用鼠标拖动可对3D模型进行全览
**鼠标跳转至原点**：点击Edit->Jump->Reference / ctrl + end

1、**放置焊盘**：在Top layer（顶层），点击快捷工具栏的黄色圆圈放置焊盘（place pad），Properties栏可修改焊盘标号、类型、形状、大小、是否挖洞
2、**控制焊盘之间的距离**：当需要控制多个焊盘之间的距离时可将多个焊盘的中心都放置在原点处，通过shift + tab选择不同的焊盘，然后按M，选择Move Selection by X/Y，填入需要的x,y轴偏移量即可
3、**重新设置原点**：点击Edit->Set Reference->Center / 快捷键EFS 将原点设置为多个焊盘的中心点
4、**绘制丝印**：丝印层为Top Overlay，下侧选择所处层为丝印层后点击绘图 / 快捷键PL可进行丝印的绘制，若丝印与阻焊重叠，丝印会被阻焊覆盖
5、**设置阻焊**：阻焊层为Top Solder，双击焊盘可在Properties栏中设置

### （三）、IPC封装创建向导的利用
1、打开封装创建项：点击Tools->IPC Compliant Footprint Wizard
2、依次对打开的封装创建项的各个选项进行配置，最后点击Finish即可创建封装

### （四）、库安装与如何调用他人的PCB库
#### 1、调用单个元件库
  在PCB图中选中需要调用的元件->点击ctrl + c->来到PCB Library栏，确认所处状态位于Footprints栏中->点击ctrl + v复制元件库
#### 2、调用多个元件库
1、在PCB图中按住shift键然后选择需要调用的多个元件，之后的步骤与调用单个元件库相同
2、进入PCB图，点击Design->Make PCB Library / 快捷键DP生成PCB库，然后将生成的PCB库中的元件复制到自己的PCB库中即可

#### 3、获取AD的官方库
1、打开网页 https://www.altium.com/documentation/other_installers ，登录AltiumLive账号后下拉页面找到**Altium Designer 23.2 Libraries**，点它的 **Download Libraries**，下载完成之后解压缩
2、将解压缩得到的库文件移动到Altium->ADAgile->Library中（可选）
3、打开AD界面，右侧点击Components，点击三条横杠的按钮，选择Libraries Preferences
4、在打开的页面上侧选择installed栏，下侧点击Install…
5、找到库文件所在的地址，选择Miscellaneous Connectors.IntLib和Miscellaneous Connectors.IntLib，点击打开
6、看到页面中出现了这两个库且无错误信息代表库文件添加成功，点击close即可，之后可以在Components栏三条横杠左侧选择要使用的库文件

#### 4、从立创商城中下载元件
1、在立创商城界面搜索栏搜索需要的元器件然后点击数据手册
2、点击右下角的立即点开
3、点击文件->导出->AD，得到一个解压包
4、在解压包中点点点文件夹找到一个(.pcbdoc)后缀的文件，双击打开它
5、使用CV大法将该元器件复制到自己的PCB库中

### （五）、PCB封装的检查与报告
>**显示弹出的选择对话框**：点击Perferences->PCB Editor->General，勾选Display Popup Selection Dialog，然后点击Apply、OK，之后当鼠标移动到多个焊盘重叠处时会弹出窗口选择想要选中的元件

1、打开PCB库
2、点击Reports->Component Rule Check后弹出元件规则检查窗口
3、勾选弹出窗口的所有选项后点击OK
4、弹出报告

### （六）、PCB封装模型调用与创建
#### 1、自己创建封装模型
1、打开需要绘制封装模型的PCB元件
2、点击Place->Extruded 3D Body
3、进行3D模型绘制，可通过shift + space改变绘制图线的拐角，绘制3D模型所在的层必须是Mechanical 1
4、切换到3D状态下对模型进行预览，双击模型更改其属性
5、在PCB Library栏选中元器件，单机右键，选择Update PCB With 元件名，在弹出窗口勾选所有选项，点击OK

#### 2、使用已有的3D模型
1、打开需要使用3D模型的PCB元件
2、点击Place->3D Body
3、找到使用的3D模型文件，选择该模型并将其加载进来
4、放置3D模型
5、通过shift + 鼠标右键移动3D模型
6、拖动3D模型状态下按space可以将元件绕x轴旋转

## 二、PCB的绘制
### （一）、PCB的布局
#### 1、原理图导入PCB
1、打开原理图，选择Design->Update PCB Document / 打开PCB，选择Design->Import Changes From
2、在弹出窗口选择Automatically，会显示PCB和原理图中有多少处不同，点击Yes，会显示可添加元件以及存在的错误，点击Execute Changes执行变更
> **原理图导入时常见问题**：
1、没有封装
2、封装名称不匹配
3、管教号没有匹配

#### 2、快速定义PCB板框
1、原理图导入PCB后选中PCB板上的所有元件
2、点击Tools->Component Placement->Arrange Within Rectangle，之后在PCB界面框选一个矩形排列元器件，板框的大小大概就是能够框选所有元器件的矩形的大小
3、执行快捷键EOS设置原点，进入Mechanical 1层，执行快捷键PL进行画线（线宽设置为10mil）
4、双击线条，通过快捷键 ctrl + Q 切换单位，将线条长度设置为整数（最好为5的倍数）
5、选中线条，按tab键选中整个线条，快捷键DSD / Design->Board Shape->Design Board Shape重新定义板框大小

#### 3、固定孔的放置
1、放置一个焊盘，将其属性修改为一个3mm的非金属大孔（焊盘和孔等大，取消勾选属性中的Plated）
2、定位孔一般放与顶点x、y轴距离 3 ~ 5mm 处

#### 4、层叠的定义及添加
1、通过快捷键DK打开层叠管理器窗口
2、Properties栏去掉Stack Symmetry的勾选，使在添加层时一层一层单独添加
3、在层叠管理器窗口选中一个层，选择insert layer above / insert layer below在该层的上方 / 下方添加层，Signal为正片层，Plane为负片层
>**正片层**：绘制导线，有导线的地方才有铜
**负片层**：绘制线条，有线条的地方没有铜

#### 5、PCB与原理图的交互
1、打开原理图和PCB，右键文件选择Split Vertical同时显示PCB和原理图
2、点击Tools->Cross Select Mode
3、在原理图中框选元器件时对应的PCB元器件也会被选中，在PCB中选中元器件时在原理图中也会有对应的元器件被选中
>**控制选中元器件的种类**：点击Perference->System->Navigation，在右侧的Objects for cross selection中只选中Components
模块化布局：在原理图中框选一个模块的元器件，点击Tools->Component Placement->Arrange Within Rectangle，之后在PCB界面框选一个矩形即可在该矩形中放置这个模块的元器件

#### 6、PCB布局中的常用操作命令
1、**框选**：按住鼠标左键后向左方框选会选中框中的所有元件，按住鼠标后向右方框选会选中框中完全包含的所有元件
2、**线选**：快捷键SL，线选会选中线经过的所有元件
3、**器件位置微调**：选中器件，按住ctrl，点击方向键对器件位置进行微调
4、**器件的换层**：拖动器件状态下点击L键
5、**器件的联合**：框选需要联合的器件，单击右键，选择Unions->Create Union from selected objects，创建联合后联合的器件成块移动
6、**器件的锁定**：双击器件，在Properties的Location栏将锁锁上，锁定后的器件不能移动

### （二）、PCB的布线
#### 1、飞线的显示和隐藏
>PCB栏需要选择Nets才能显示飞线
* **单个飞线的隐藏**：快捷键NHN，然后点击焊盘即可隐藏与该焊盘相连的飞线
* **单个飞线的显示**：快捷键NSN，然后点击焊盘即可显示与该焊盘相连的飞线
* **器件飞线的隐藏**：快捷键NHO，然后点击器件即可隐藏与该器件相连的飞线
* **器件飞线的显示**：快捷键NSO，然后点击器件即可显示与该器件相连的飞线
* **整体飞线的隐藏与显示**：快捷键L，System Colors栏，点击其中的Connection Lines的左侧小眼睛可以显示与隐藏飞线
* **网络对应的飞线的隐藏与显示**：PCB栏的Nets栏中选择网络，右键，选择Connections后选择Hide / Show即可隐藏 / 显示网络对应的飞线

#### 2、Class的创建和应用
##### （1）、网络类
* **添加类**：快捷键DC进入类别窗口，Nets Classes处右键选择Add Class，输入类名称添加类，向类中添加属于该类的网络，点击OK
* **更改类的布线线宽**：Design->Rules，在弹出的窗口左侧栏选择Routing->Width，右键Add Rule，选择网络类并将线宽修改为该类需要的线宽
##### （2）、差分类
* **添加类**：快捷键DC进入类别窗口，Differential Pair Classes处右键选择Add Class，输入类名称添加类，向类中添加属于该类的成员，点击OK

#### 3、PCB布线的常用操作命令介绍
>**推荐的布线顺序**：信号->电源->GND
**推荐的打孔方式**：错位打孔

* **布线**：点击Route->Interactive Routing，进行布线
* **多根走线**：框选需要共同布线的电线，执行快捷键UM，shift + R可切换到忽略障碍物走线
* **网络化粘贴**：复制需要粘贴的走线，点击Edit->Paste Speical，只勾选Keep net name，然后点击Paste，将粘贴到的走线放置到需要的位置
* **元器件文本放置位置选择**：选中器件，按A，点击Position Component Text选择元器件文本放置位置
* **删除布线**：点击快捷键UUC，然后点击需要删除的走线即可删除

#### 4、Active Route的自动布线
>**激活Active Route**：点击右上角登录处，选择Extensions and Updates，勾选ActiveRoute，Apply并重新启动

1、点击Panels->PCB ActiveRoute，弹出自动布线配置窗口
2、在窗口界面勾选Tune Selected，使选择的走线会自动进行调整
3、选择布线所在的层
4、按住Alt键，向左上角滑动选中需要自动布线的飞线
5、执行Route Guide，绘制走线大概路径
6、点击ActiveRoute自动执行走线

#### 5、泪滴
##### （1）、泪滴的作用
* 避免电路板受到巨大外力冲撞时导线与焊盘或导线与导线的接触点断开
* 保护焊盘，避免多次焊接时焊盘脱落；避免蚀刻不均，过孔偏位出现的裂缝
* 信号传输时平滑阻抗，减少阻抗的急剧跳变；避免高频信号传输时由于线宽突然变小而造成反射，可使走线与元件焊盘之间的连接趋于平稳过渡化
  
##### （2）、泪滴的添加与移除
1、点击快捷键TE，弹出泪滴添加窗口
2、进行泪滴添加或移除相关配置
3、点击OK添加或移除泪滴

### （三）、PCB敷铜
>**敷铜属性配置**：点击Perference->PCB Editor->Defaults，选择Polygon进行敷铜属性配置，敷铜模式建议选择Hatched，Track Width 和 Grid Size 分别选择5mil和4mil，选择Pour Over All Same Net Objects，勾选Remove Dead Copper，点击Apply、OK

#### 1、PCB的敷铜
1、点击快捷键PG激活敷铜配置
2、绘制敷铜区域
3、选中敷铜区域，右键，选择Polygon Actions->Repour Selected进行敷铜

#### 2、Cutout的放置及敷铜的修正优化
##### （1）、直接绘制Cutout区域
1、点击Place->Polygon Pour Cutout
2、绘制Cutout区域
3、选中Cutout区域，右键，选择Polygon Actions->Repour Selected挖掉Cutout区域中的铜
##### （2）、通过已经通过图像绘制的图形绘制Cutout区域
1、通过图像绘制绘制出Cutout区域，并选中该区域的线条
2、点击Tools->Convert->Create Cutout from… / 快捷键TVT
3、删除绘制图形的线条，Cutout区域已绘制
4、右键，选择Polygon Actions->Repour Selected挖掉Cutout区域中的铜
##### （3）、敷铜的优化
点击快捷键PY，可裁剪多边形敷铜编辑现有铜皮

### （四）、常用规则
>**规则错误实时检查**：快捷键TD，勾选需要检查的规则对应选项的online
**打开规则配置窗口**：快捷键DP

#### 1、间距规则
* **间距规则所在位置**：选择规则配置窗口中左侧栏的Electrical->Clearance
* **间距规则属性配置**：建议最小间距6mil，勾选Ignore Pad to……

#### 2、布线线宽规则
* **线宽规则所在位置**：选择规则配置窗口左侧栏的Routing->Width
* **设置电源布线线宽规则**：Width处右键Add Rule，新规则命名为PWR，Where The Object Matches处选择Net Class，Class选择自己创建的电源线类PWR，首选宽度12mil、最小宽度12mil、最大宽度60mil

#### 3、过孔规则、阻焊规则
* **过孔规则**：设置布线中过孔的尺寸，可以设置的参数有过孔焊盘的直径和过孔中的通孔直径，孔径一般选择12mil，过孔直径一般选择24mil，所在位置为规则配置窗口的Routing->Routing Via Style
* **阻焊规则**：所在位置为规则配置窗口的Mask->Solder Mask Expansion，可以设置阻焊的外扩，推荐设置为2.5mil

#### 4、全连接及十字花焊盘链接铺铜规则
* **铺铜规则所在位置**：规则配置窗口左侧栏的Plane->Polygon Connect Style
* **通孔焊盘连接**：默认为十字花焊盘连接，散热均匀
* **表贴焊盘连接**：默认十字花焊盘连接
* **Via Connection**：过孔的连接，一般默认设置为全连接

#### 5、差分规则
* **差分规则所在位置**：规则配置窗口左侧栏的Routing->Differential Pairs Routing，
* **属性设置**：建议线宽全部设置为5mil、间距全部设置为7mil

#### 6、规则的使能及优先级设置
* **规则的优先级配置**：规则配置窗口选择Priorities即可进行优先级相关配置
* **规则的使能**：选中该类规则的选项，勾选需要使能的规则的Enable

#### 7、规则的导出与导入
**导出**：
1、打开规则配置窗口，任意选择一个规则，右键，选择Export Rules
2、选择需要导出的规则，点击OK
3、选择规则文件保存位置和名称
**导入**：
4、打开规则配置窗口，任意选择一个规则，右键，选择Import Rules
5、选择需要导入的规则，点击OK
6、选择使用的规则文件，点击Yes导入规则

## 三、PCB的DRC电气性能检查
>**确定双击DRC报错时可以弹到具体位置**：点击Perference->System->Navigation，右侧Zooming处的右侧选择Close

1、快捷键TD打开DRC配置窗口
2、左侧栏选择Report Options可配置DRC检查报告相关选项，其中最大报错数量建议配置为50000
3、左侧栏选择Rules Types To Check进行DRC检查相关配置，Online标识实时显示错误、Batch表示生成DRC报告时显示该错误，默认全部勾选
4、点击DRC配置窗口左下侧Run Design Rule Check，生成DRC报告

## 四、PCB的善后处理

### （一）、PCB尺寸大小标注
1、快捷键PDL激活线性尺寸放置选项
2、左键选择放置线的一端的位置在PCB一端，将线的另一端放置在PCB的另一端，按space可切换标注模式（横向标注、竖向标注）
3、按tab键对显示的线性尺寸的单位和小数位数进行设置，线上会自动显示长度，对PCB的尺寸进行标注

### （二）、PCB的点到点与边缘距离测量
* **点到点的距离测量**：快捷键ctrl + M / RM进行点到点的距离测量
* **边缘距离测量**：快捷键RP，点击两个器件进行边缘距离的测量
* **测量走线长度**：选中需要测量长度的走线，点击快捷键RS，弹出窗口显示选中对象的测量长度

### （三）、器件位号丝印的调整原则
* 丝印位号不上阻焊，避免放置丝印生产之后确实
* 丝印位号清晰，字号推荐字宽 / 字高尺寸为4 / 25mil、5 / 30mil、6 / 45mil
* 保持方向统一性，推荐字母在左或在下

### （四）、PCB板图片放置（LOGO以及二维码）
1、点击Place->Graphics，进入图片放置状态
2、框选图片尺寸，选择导入的位图（.bmp后缀）
3、选择导入的配置，点击Ok导入图片

### （五）、多层线路及装配图PDF的输出
1、打开PCB文件，点击File->Smart PDF，弹出PDF输出配置窗口
2、选择输出的文档、输出的PDF文件的名称及位置
3、在打印设置处的上侧栏单击右键，选择Create Assembly Drawings创建装配图，装配图一般只保留丝印层、机械1层、阻焊层；选择Insert Printout输出打印选项，添加打印选项进行分层打印

### （六）、生产Gerber文件的输出步骤
#### 1、Gerber文件的输出
1、点击File->Fabrication Outputs->Gerber Files，弹出Gerber设置窗口
2、在Gerber设置界面单位选择英尺（mil），确定需要的精度，勾选include unconnected mid-layer pad；Plot layers选择Select Used只勾选使用的层，去掉不需要用于生产的层
3、生成Gerber文件
#### 2、钻孔文件的输出
1、点击File->Fabrication Outputs->NC Drill Files，弹出钻孔文件设置窗口
2、Unils选择Inch，Format选择2:4
3、点击OK生成钻孔文件
#### 3、网表文件的输出
1、点击File->Fabrication Outputs->Test Point Report，弹出网表文件设置窗口
2、Report Formats栏只勾选IPC-D-356A
3、点击OK生成网表文件
#### 4、器件坐标图的输出
1、点击File->Assembly Outputs->Generates pick and place files
2、选择需要输出的器件
3、点击OK生成器件坐标图

# 挑战点七：四轴飞行器转接板原理图及PCB图设计与制作

## 一、原理图符号和PCB封装的准备
**原理图库和PCB库中需要的元器件：**
* STM32F401Nucleo评估板：左右两个2X19的接口
* GY-86模块：一个1X8的接口
* HM-10蓝牙模块：一个1X6的接口
* SBUS转TTL模块：一个1X3的接口
* OLED模块：一个1X4的接口
* PWM输出口：一个1X3的接口
* SS12D06开关：一个1X3的接口
* XT-30PW：一个1X2的接口及两个固定口

>通过嘉立创获得原理图符号及PCB封装：
1、搜索嘉立创EDA网页版，进入嘉立创官网，右上方点击嘉立创EDA编辑器，选择专业版
2、新建一个项目，在库中查找需要准备的元件将原理图符号放置在原理图中，PCB封装放置在PCB上
3、点击文件->导出->Altium Designer，生成该项目的AD项目
4、打开生成的AD项目，通过其原理图和PCB生成原理图库和PCB库，复制粘贴自己所需要的元件

## 二、原理图的绘制
### （一）、引脚分配
**需要分配的引脚：**
- 四路电机和STM32F401Nucleo板的连接：四路PWM
- GY-86模块、OLED模块和STM32F401Nucleo板的连接：两路I2C
- HM-10蓝牙、乐迪R8EF接收机通过SBUS转TTL模块和STM32F401Nucleo板的连接：两路USART

### （二）、引脚连接
#### 1、供电引脚
- **+5V**:与TIM2_CH2通道连接的电调的BEC接口提供+5V电源，该电源与GY-86模块的+5V、SBUS转TTL模块的+5V、STM32F401Nucleo板的E5V连接，为这些模块供电
- **+3V3**：+3V3的电源由STM32F401Nucleo板的一个+3V3引脚提供，该电源与OLED模块的+3V3、HM-10蓝牙模块的+3V3连接，为这些模块供电
- **GND**：STM32F401Nucleo板、四路电调、GY-86、OLED、HM-10蓝牙、SBUS转TTL的GND通过敷覆盖在整块PCB板上的铜的方式相互连接
#### 2、信号引脚
- **I2C**：GY-86模块使用I2C1通信，SCL与PB6相连、SDA与PB9相连；OLED使用I2C2通信，SCL与PB10相连、SDA与PB三相连
- **USART**:HM-10使用USART1通信，RX与PA9相连、TX与PA10相连；SBUS转TTL模块使用USART2通信，TX与PA3相连
- **PWM**：四路PWM分别使用TIM3_CH1、TIM3_CH2、TIM3_CH3、TIM3_CH4，四路电调的信号线分别与PA6、PA7、PB0、PB1相连

## 三、PCB的绘制

### （一）、原理图导入PCB
1、打开PCB文件，选择Design->Import Changes From
2、在弹出窗口选择Automatically，会显示PCB和原理图中有多少处不同，点击Yes，会显示可添加元件以及存在的错误，点击Execute Changes执行变更

### （二）、快速定义PCB板框
1、原理图导入PCB后选中PCB板上的所有元件
2、点击Tools->Component Placement->Arrange Within Rectangle，之后在PCB界面框选一个矩形排列元器件，板框的大小大概就是能够框选所有元器件的矩形的大小
3、执行快捷键EOS设置原点，进入Mechanical 1层，执行快捷键PL进行画线（线宽设置为10mil）
4、双击线条，通过快捷键 ctrl + Q 切换单位，将线条长度设置为整数（最好为5的倍数）
5、选中线条，按tab键选中整个线条，快捷键DSD / Design->Board Shape->Design Board Shape重新定义板框大小

### （三）、固定孔的放置
通过观察机架结构，选择在PCB板中心打出`一个半径为14mm的大圆孔`用于电调接线，大圆孔四周打出`四个半径为3mm的小圆孔`作为PCB与机架连接并固定的固定孔

### （四）、PCB布局
#### 1、PCB上需要放置的元件
- STM32F401Nucleo板：水平放置，通过PCB上的母杜邦口插入到PCB上
- 四路PWM引脚：通过两路2X3的2.54mm排针引脚与四个电调的PWM信号线连接
- GY-86模块：水平放置，焊接到PCB上
- OLED模块：水平放置，焊接到PCB上
- HM-10蓝牙模块：竖直放置，通过PCB上的母杜邦口插入到PCB上
- SBUS转TTL模块：竖直放置，通过PCB上的母杜邦口插入到PCB上
- SS12D06开关：竖直放置，焊接到PCB上
- XT-30PW公口：水平放置，焊接到PCB上

#### 2、PCB封装放置位置
- STM32F401Nucleo板：放置在PCB的中间
- 四路PWM引脚：两路2X3的2.54mm排针引脚分别放置在PCB中心的上侧和下侧
- GY-86模块：放置在PCB的右侧中间
- OLED模块：放置在PCB左侧中间
- HM-10蓝牙模块：放置在PCB的左下方
- SBUS转TTL模块：放置在PCB的右下方
- SS12D06开关：放置在PCB的左上方
- XT-30PW:放置在PCB的左上方

### （五）、PCB的布线
根据鼠线完成PCB上的布线。+5V、+3V3采用树干式布线，线宽8mil；信号线一一对应连接，线宽4mil。GND采用在整块PCB上的Top Layer层和Bottom Layer层敷铜的方式连接，在布线时只需要引出一小段电线即可

### （六）、泪滴的添加
1、点击快捷键TE，弹出泪滴添加窗口
2、在弹出窗口选择All，为所有需要添加泪滴的地方添加泪滴
3、点击OK添加泪滴

### （七）、PCB敷铜
>**敷铜属性配置**：点击Perference->PCB Editor->Defaults，选择Polygon进行敷铜属性配置，敷铜模式建议选择Hatched，Track Width 和 Grid Size 分别选择5mil和4mil，选择Pour Over All Same Net Objects，勾选Remove Dead Copper，点击Apply、OK

1、将所处层修改为Top Layer / Bottom Layer层，点击快捷键PG激活敷铜配置
2、按tab键进入属性设置，Net选项选择GND
3、绘制敷铜区域，敷铜区域应该是整个PCB矩形，但距离PCB边框距离不得小于0.3mm
4、选中敷铜区域，右键，选择Polygon Actions->Repour Selected进行敷铜

### （八）、丝印绘制
将所处层更换为Top Overlay，在丝印层添加文本，注明PCB相关信息、各个模块的名称以及引脚的具体定义

### （九）、PCB的DRC电气性能检查
>**确定双击DRC报错时可以弹到具体位置**：点击Perference->System->Navigation，右侧Zooming处的右侧选择Close

1、快捷键TD打开DRC配置窗口
2、左侧栏选择Report Options可配置DRC检查报告相关选项，其中最大报错数量建议配置为50000
3、左侧栏选择Rules Types To Check进行DRC检查相关配置，Online标识实时显示错误、Batch表示生成DRC报告时显示该错误，默认全部勾选
4、点击DRC配置窗口左下侧Run Design Rule Check，生成DRC报告
5、根据生成的DRC报告处理PCB中存在的错误

### （十）、PCB尺寸大小标注
1、快捷键PDL激活线性尺寸放置选项
2、左键选择放置线的一端的位置在PCB一端，将线的另一端放置在PCB的另一端，按space可切换标注模式（横向标注、竖向标注）
3、按tab键对显示的线性尺寸的单位和小数位数进行设置，线上会自动显示长度，对PCB的尺寸进行标注

## 四、PCB下单
### （一）、输出Gerber
1、点击File->Fabrication Outputs->Gerber Files，弹出Gerber设置窗口
2、在Gerber设置界面单位选择英尺（mil），确定需要的精度，勾选include unconnected mid-layer pad；Plot layers选择Select Used只勾选使用的层，去掉不需要用于生产的层
3、生成Gerber文件
### （二）、输出钻孔文件
1、点击File->Fabrication Outputs->NC Drill Files，弹出钻孔文件设置窗口
2、Unils选择Inch，Format选择2:4
3、点击OK生成钻孔文件
### （三）、生成用于下单的压缩包
打开绘制PCB的AD项目的"Project Outputs for AD"文件夹，选中AD.GTL、AD.GBL、AD.GTO、AD.GBO、AD.GTS、AD.GBS、AD.GM1、AD.TXT，右键创建.zip压缩包
### （四）、嘉立创下单
1、打开嘉立创官网，进入[PCB下单页面](https://www.jlc.com/newOrder/#/pcb/newOnlinePlaceOrder?spm=jlc-pc.newcenterpage.business&jlc_vid=ElVYBVAAQARZBVJVQAdaVgFXEQdcAVcDQFBeVFxXRFgxVlNfRVBaU1JfQ1RdUTsOAxUeFF5JWBYZEEoEHg8JSQcJGk4xDxASBxJUSEsRABZADQgFWQIBCg%3D%3D)进行下单 / 下载嘉立创下单助手通过下单助手下单
2、选择上传PCB，将创建的压缩包上传，生成相应的下单文件，点击立即下单进入下单配置页面
3、选择板材为FR-4、层数双层板、焊盘喷镀选无铅OSP、个性化服务选【按标准合同常规处理】、板上加标志选择不加任何标志、SMT贴片 / 钢网视需求选择、发货方式选择不同交期订单一起发货
4、完善开票自资料及收货信息
5、选择检查订单，消除红色错误后提交订单
6、订单审核，下载嘉立创下单助手，审核成功后下单助手发送信息进行支付
